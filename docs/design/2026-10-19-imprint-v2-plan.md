# Kari Imprint v2：质量、效果与交互重构计划

状态：执行中。2026-10-19。基于三份调研：信息边框排版/特效调研、渲染边界测试（scratchpad 复现脚本）、immich-ki WebUI 审查。
部署由 NAS 端 agent 完成；本分支只负责代码、自动验证和提交。

## 一、调研结论（摘要）

- 业界主流（小米徕卡、semi-utils、darktable）：底栏为短边 9–15%；主行粗体 / 副行常规，字号比约 1 : 0.85；
  主色 #000–#242424、副色 #737373–#8A8A8A、分隔线 #D3D3D3–#D8D8D6；Logo 与两行文字同高（底栏 40–45%）。
- 参数格式：`35mm f/1.8 1/250s ISO 100`；光圈去尾零；无效值（0、undef）整项隐藏。
- 特效：模糊背景悬浮卡片（下采样后模糊 + 叠暗层 + 抖动）、柔和投影、抗锯齿圆角、深色模式（Logo 反白）。
- 长文字：先缩字号（下限约 80%），再截断加省略号；绝不越过分隔线 / 画布。

## 二、渲染正确性（P1/P2 必修）

1. 横排文字按可用宽度缩放 + 省略号截断（TS 预览与 PIL 同步，不越过分隔线和画布）。
2. 品牌无法识别 / 无 EXIF：不预留 Logo 空间、不画孤立分隔线（两端一致）。
3. EXIF 保留 CJK/希腊字母等非 ASCII，只剥离控制字符。
4. 无效参数（f/0、0mm、0s、undef）整项隐藏；焦距回退实际焦距；光圈去尾零；`ISO 100`。
5. 分隔线半透明正确合成、尺寸与预览一致。
6. 16 位 / LA+ICC 图像正确转换。
7. 颜色校验改正则；子进程错误码透传（output_too_large 等）。
8. 品牌别名表（Phase One、Arashi Vision→Insta360、PENTAX、OM System 等）；小 Logo 按槽位等比放大。
9. 深色背景自动对比：文字/分隔线/Logo 方案按背景亮度推导，而不是只认 3 个固定色。
10. 侧栏主次层级、文字与分隔线间距对称、Logo 不越过内边距。

## 三、效果

- 新增「深色信息框」样式（深底、浅字、Logo 反白方案）。
- 新增「模糊背景」样式：照片悬浮在自身模糊放大的背景上，可选圆角与柔和投影；信息文字白色居中。
  画布配置新增 `canvas.effect`（TS/Python/API schema 同步，旧配置缺省为纯色背景）。

## 四、交互重构（immich-ki web）

- 修复：键盘撤销陈旧闭包、字段勾选双轨错位、纯留白切位置偷换样式、保存后再改仍显示“已保存”、
  选中框不重绘、输入框内 Esc/⌘S、无效的全局默认文字、间距单位偷换、样式切换清空设置、图库角标优先级。
- 编辑页：隐藏相册栏，两栏布局；顶栏 返回 · 序号 · ‹ › · 文件名 · 状态胶囊（未改/未保存/处理中/已保存/失败分色）；
  预览下方胶片条；右栏首屏为样式卡（用当前照片缩略实时渲染）→ 位置 → 留白；信息/品牌/署名/精细依次折叠；
  底部吸附：目的地 + 保存到 Immich + 保存并下一张 + 下载。维护与备份移到页头。
- 预览：适应 / 放大检查 / 按住（或空格）看原图。
- 批量：复制上一张设置；应用当前样式到所选或本相册其余照片（写本机草稿，不自动生成），一键全部保存。
- 撤销合并连续输入；dirty = 与已保存配置不同；轮询退避；错误文案去掉 `Error:` 前缀。
- 图库：行优先网格（视觉顺序 = 键盘顺序）、状态筛选、单一状态机角标（处理中 > 失败 > 草稿 > 有成品 > 未制作）。
- 手机：预览吸顶、折叠分区设置、吸底保存栏、安全区；相册为横向滚动条。

### 交互决策记录

- 切换照片 / 返回图库不再弹出“未保存离开”对话框：修改自动保存为**本机草稿**（按账户 + 照片隔离），
  以 toast 告知并提供“放弃草稿”；图库角标显示“草稿”。这样连续切图不被打断，同时不丢修改、不冒充已保存。
- 状态胶囊只在 Immich 收录确认后显示“已保存到 Immich”；保存后再修改显示“有未保存修改 · Immich 中仍是上次成品”。
- 批量操作不自动生成：多选 → 粘贴设置为草稿 → 用户确认“保存 N 份草稿到 Immich”。
- 预览“放大检查”按设备像素显示预览栅格（预览最长边受 capabilities 限制），不是原图 100%。
